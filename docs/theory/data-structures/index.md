# 数据结构基础

<section class="index-block" markdown>
<p class="index-block__title">概要</p>

离散数学和数据结构基础是一起上的，这里前置课程只是说他们之间在**图算法**模块有些重叠。同时如果想严格的证明、理解FDS的一些算法的话离散数学挺有帮助的。

虽然 FDS 考试对证明的要求并不很高（有少量创新题目可能需要对证明和原理有一些理解，个人感觉） ，不过感觉严格理解算法还是对后续的ADS有用的，因为有时候会渐渐觉得有些算法一点都不显然。

同时这门课还会第一次涉及代码作业PTA互评...可以提前熟悉一下流程，本人因为第一次不熟悉被迎头痛击...

**前置课程：** [离散数学](../discrete-mathematics/)
