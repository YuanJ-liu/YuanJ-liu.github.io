# 数字逻辑设计

<section class="index-block" markdown>
<p class="index-block__title">概要</p>

这门课是系统课的起点。学的时候可能会逐渐接触一些工程性的问题，所以笔记里一般会先给出**要解决的问题**或者**动机**之类的，或者至少把我们要设计的东西的**功能**叙述严谨清楚一点，应该能把思路理顺，不然感觉学完了很快就会忘掉（雾）

</section>
